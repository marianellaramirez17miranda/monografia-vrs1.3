# Conclusiones

Las conclusiones responden directamente a los objetivos planteados. No deben
incluir información nueva ni citas extensas.

1. **Primera conclusión.** Resuma el hallazgo principal relacionado con el
   primer objetivo específico.
2. **Segunda conclusión.** Resuma el hallazgo principal relacionado con el
   segundo objetivo específico.
3. **Tercera conclusión.** Resuma el hallazgo principal relacionado con el
   tercer objetivo específico.

## Recomendaciones

Si su asesor lo solicita, incluya sugerencias para futuras investigaciones o
para la aplicación práctica de lo encontrado.
